# 🚀 Nigam Patel — Personal Portfolio

Welcome to my personal developer portfolio! This website showcases my projects, technical skill stack, academic journey at **Dayananda Sagar Academy of Technology and Management (DSATM)**, and contact links.

Live Profile: [LinkedIn Profile](https://www.linkedin.com/in/nigam-patel-h-19668b383)

---

## 🛠️ Built With

- **HTML5**: Semantic elements, accessible modals, and structured metadata.
- **CSS3**: Custom design tokens, glassmorphism, responsive grids, and micro-animations.
- **JavaScript (ES6+)**: Interactive background particle mesh canvas, 3D card tilt effect, dynamic typewriter, project modals, and real-time category filtering.

---

## 🌟 Highlights & Features

- **Hero Profile Showcase**: 3D perspective tilt card with interactive status indicators.
- **Dynamic Typewriter**: Highlighting Web Development & App Development specializations.
- **Interactive Background Constellation**: Connected canvas particles reacting to mouse movement.
- **Projects Matrix**: Filterable showcase for Web & Mobile applications with deep-dive modals.
- **Interactive Contact Hub**: One-click email copy with toast notification and functional contact form.
- **Resume Preview**: Built-in resume preview modal with print / save-as-PDF capability.

## 💻 Running Locally

Simply open `index.html` in your browser, or start a local server:

```bash
# Python local server
python -m http.server 8000
```

Then visit `http://localhost:8000` in your web browser.
